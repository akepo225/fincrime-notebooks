# Finding Mule Networks

Companion for the article *Finding Mule Networks in Transaction Graphs: A Practitioner's Field Guide*.

- **Everything is synthetic.** No real bank, client, account, payment, or device. The week is a fixed edge list written for this article, not a draw from a real book.
- **The figures and the quoted numbers are regenerated by this script.** Degree is fixed by that edge list. The Louvain seed is fixed at 42. Betweenness and the community assignment are whatever this script prints.

Related project: see the repository README.

## Run it

From this folder:

```bash
uv run --no-project --with "networkx==3.7" --with "matplotlib==3.11.2" python find_mule_networks.py
```

Tested with Python 3.12. The script prints degree, the pass-through edges, directed betweenness, and one seeded Louvain partition, and it writes two figures to `figures/`.

A second run of that command is byte-identical for `figures/fig1_three_drawings.png` and `figures/fig2_ledger_degree.png`, and it prints the same degree, betweenness, and community assignment. Compare the two figure hashes and the two stdout files.

## What to look at

- Ledger degree: wage payer 8, merchant 6, exit 3, employee-mule 3, each pure mule 2, the employee who pays rent 2, each household account 1.
- Pass-through window: 6 hours. The rule fires on the three mule accounts and on the employee who pays rent.
- Directed betweenness on the pass-through graph, normalised, endpoints excluded. The highest score is a four-way tie.
- The Louvain community of the employee who is also a mule. The script places that account in one community.

Node positions are fixed coordinates. The Louvain seed is 42. Do not replace the layout with an unseeded spring layout.
